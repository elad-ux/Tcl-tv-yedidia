# הרזיית טלוויזיית TCL (Android TV 9/10/11) – YouTube + אפליקציית ספק בלבד

## שורה תחתונה
- הסקריפט `tcl_slim.py` **מכבה** (לא מוחק) את כל האפליקציות מלבד YouTube ואפליקציית ספק הטלוויזיה (סלקום TV / yes+ / HOT / פרטנר TV), ומקצר אנימציות.
- הכל הפיך: `--restore` מחזיר את המצב.
- **ציפייה מציאותית:** זה ישפר תגובתיות, אבל לא יהפוך מעבד חלש למהיר. בהרבה דגמי TCL ישנים יש 1.5–2GB זיכרון ומעבד בסיסי. אם אחרי כל הצעדים זה עדיין איטי, הפתרון האמין הוא סטרימר חיצוני (למשל Google TV Streamer / Chromecast with Google TV) מחובר ל-HDMI.

## שלב 0 – מה עושים בלי מחשב (לעשות קודם)
1. הגדרות ← אפליקציות ← לכל אפליקציה שלא צריך: **השבת / הסר התקנה**.
2. הגדרות ← אפליקציות ← YouTube ואפליקציית הספק ← **נקה מטמון** (לא "נקה נתונים" – זה ינתק אותך).
3. במסך הבית: לחיצה ארוכה על אפליקציה ← "הסר ממועדפים" כך שיישארו רק השתיים. ניתן גם להסתיר שורות ("התאמה אישית של ערוצים").
4. **עדכון מערכת**: הגדרות ← העדפות מכשיר ← אודות ← עדכון מערכת.
5. נתק מהחשמל ל-30 שניות (אתחול מלא, לא רק כיבוי מהשלט).

אם זה מספיק – עצור כאן.

## שלב 1 – הפעלת ADB בטלוויזיה
1. הגדרות ← העדפות מכשיר ← אודות ← לחץ 7 פעמים על **Build** עד "אתה מפתח".
2. הגדרות ← העדפות מכשיר ← אפשרויות למפתחים ← הפעל **USB debugging** (ובחלק מהדגמים גם Network/ADB debugging).
3. רשום את כתובת ה-IP: הגדרות ← רשת ← סטטוס (למשל `192.168.1.50`). המחשב והטלוויזיה חייבים להיות באותה רשת.

## שלב 2 – במחשב
1. התקן [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools) ו-[Python 3](https://www.python.org/downloads/).
2. הרצה יבשה (לא משנה כלום, רק מציג):
   ```
   python tcl_slim.py --ip 192.168.1.50
   ```
   בטלוויזיה תופיע בקשה "Allow USB debugging" – אשר (סמן "Always allow"). אם נכשל בפעם הראשונה – הרץ שוב.
3. הסקריפט יזהה את אפליקציית הספק ויבקש לאשר אותה. **עבור על הרשימה** שהוא מתכוון לכבות.
4. ביצוע בפועל:
   ```
   python tcl_slim.py --ip 192.168.1.50 --apply
   ```
   הטלוויזיה תופעל מחדש.
5. ביטול הכל:
   ```
   python tcl_slim.py --ip 192.168.1.50 --restore
   ```

## מה לא נוגעים בו (בכוונה)
מסך הבית, הגדרות, שירותי Google, Play Store (נדרש לעדכוני שתי האפליקציות), WebView, מקלדת, חיפוש קולי, Chromecast מובנה, וכל חבילות `com.tcl.*` / שבבים (כניסות HDMI, תמונה, טיונר). כיבוי של אלה עלול לשבור את הטלוויזיה.

## הסתייגויות
- שמות החבילות המדויקים של אפליקציות הספקים הישראליים **לא אומתו** – לכן הסקריפט מזהה אותם בטלוויזיה עצמה ומבקש אישור.
- רשימת ה"bloat" מבוססת על חבילות Android TV נפוצות; בדגם שלך ייתכנו אחרות. אפליקציות TCL ייעודיות לא מכובות אוטומטית.
- עדכון מערכת של TCL עשוי להחזיר אפליקציות מכובות – פשוט הרץ שוב עם `--apply`.
- TalkBack (קורא מסך) מכובה – אם מישהו בבית משתמש בו, הסר אותו מ-`KNOWN_BLOAT` בסקריפט.
